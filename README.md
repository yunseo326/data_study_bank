# Data Study Bank

Kaggle 대회를 순서대로 학습하며 EDA, 검증, 피처 엔지니어링, 모델링 과정을 기록하는 저장소입니다.

## Repository structure

- `bank/data/`: Kaggle 원본 데이터(로컬 전용, Git 제외)
- `bank/notebooks/`: 탐색 및 실험 노트북
- `bank/src/`: 재사용 가능한 분석·모델링 코드
- `docs/`: GitHub Pages에 공개되는 HTML 리포트

공개 리포트: <https://yunseo326.github.io/data_study_bank/>

GitHub Pages는 `main` 브랜치의 `/docs` 폴더에서 배포합니다. 리포트 파일을 수정해 `main`에 push하면 자동으로 갱신됩니다.
