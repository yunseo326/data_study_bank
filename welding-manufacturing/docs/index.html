01 / DATA UNDERSTANDING

같은 파일, 다른 단위

FULL DATA · NO SAMPLING

Excel의 Raw data는 용접 측정 한 행씩, result는 날짜와 불량 유형별 한 행씩 기록합니다. 공통 날짜만으로 두 자료를 개별 용접 수준에서 결합할 수 없습니다.

가압력, 전류, 전압, 통전시간과 두께를 포함한 측정 기록. 날짜는 9개입니다.

B / RESULT

result

23 행 × 7열

날짜·유형별 defect 숫자. 측정 행과 연결되는 고유키가 없습니다.

현재의 결론

개별 용접 불량 예측은 아직 실행할 수 없습니다. 23행의 수치를 11,939행에 복제하면 실제로 없는 정답을 만들어 학습하게 됩니다.

관측 범위

2020년 3월 24일부터 4월 7일까지 9개 날짜. 설비는 Spot-01, 품목은 65235-25800 하나씩이며 두께 두 열은 모두 0.7 mm입니다.

파일 처리 규모

전체 Excel과 CSV를 읽고 기본 품질 진단까지 수행한 3회 측정의 중간값은 4.656초였습니다. 현재 EDA에서 표본 추출은 필요하지 않습니다. 모델 학습 시간은 미측정입니다.

02 / LABEL INTERPRETATION

라벨은 무엇을 뜻하나

FACTS ≠ ASSUMPTIONS

defect type의 코드와 이름은 원본 시트에서 직접 확인됩니다. defect 숫자의 단위와 집계 규칙은 설명되지 않았습니다.

원본 result 시트 F2:G4에 기록된 불량 유형
코드원본 이름말뜻 수준의 설명확인되지 않은 기준
1파임불량용접 부위가 파이거나 움푹해진 상태를 가리키는 이름파임 깊이·위치·검사 기준
2용접부족용접이 충분하지 않다는 뜻의 이름강도·용접량 기준
3크랙발생균열이 발생했다는 뜻의 이름균열 크기·위치·검사 방법
기록된 값0, 1, 2, 3

defect 열의 실제 값. 0은 정상 측정 한 행, 1은 불량 측정 한 행이라는 뜻으로 확인되지 않았습니다.

값의 합39

23개 결과 행에 적힌 숫자를 더한 값. 검사 모집단과 집계 정의가 없으므로 확정된 불량품 수나 불량률로 부르지 않습니다.

미기록2가지

3월 27일은 결과 행 전체가 없고, 3월 31일은 유형 3 행이 없습니다. 행 부재를 0으로 채우지 않습니다.

유형별 defect 값의 합은 코드 1이 14, 코드 2가 13, 코드 3이 12입니다. 이는 기록된 수치의 합이며 유형별 확정 불량 건수는 아닙니다.

값 읽기 예시

2020-03-24 · 유형 1 · defect=2는 그 날짜의 파임불량 유형 행에 숫자 2가 있다는 뜻까지 확인됩니다. 특정 측정 2건의 불량, 2%의 불량률, 심각도 2단계 중 어느 의미인지는 알 수 없습니다.

04 / DECISION PATH

다음은 무엇을 확인하나

BEFORE BASELINE
  1. 01

    정답의 단위를 확인한다

    개별 측정 행과 검사 결과를 연결하는 고유키, 검사 시점, defect의 단위·집계 규칙, 빠진 날짜·유형의 의미를 확보합니다.

    필수
  2. 02

    검증 기준을 고정한다

    날짜별 생산 기록과 중복 조건을 고려해 시간·그룹 누수를 점검합니다. target, metric, Primary Validation을 첫 공식 실험 전에 확정합니다.

    정답 확보 후
  3. 03

    동일 조건에서 모델을 비교한다

    대회 요구에 맞춰 베이스라인 포함 두 개 이상을 같은 검증 기준으로 비교합니다. 모델의 실패조건과 False Negative/Positive는 검증 예측으로 분석합니다.

    검증 확정 후
  4. 04

    안정 공정조건을 제안한다

    관측 범위와 표본 수, 상호작용, 예측 불확실성을 함께 제시합니다. 품질과 연결된 근거 없이 저위험 설정을 확정하지 않습니다.

    모델 검증 후
현재 상태

이 보고서는 전 행 탐색 결과입니다. 모델 성능, 불량률, 공정 최적 범위는 아직 산출하지 않았습니다. 현재 파일만으로 계산하면 근거가 부족합니다.
