Feature를 어떻게 읽고 모델에 넣는가

Feature는 비료를 고를 때 모델이 참고하는 입력 정보입니다. 이 데이터에는 환경 3개, 재배 조건 2개, 영양소 3개가 있습니다. 아래의 “예상 영향”은 실험 전 가설이며, 높고 낮음 자체가 좋다는 뜻은 아닙니다. 어떤 작물·토양·다른 영양소와 함께 나타나는지가 핵심입니다.

Temparature 수치 · 14값

재배 환경의 온도 조건입니다. 원본 열 이름의 철자를 그대로 사용합니다.

예상: 작물과 습도에 따라 적합한 비료 조건이 달라질 수 있어 온도 × 작물, 온도 × 습도를 후보로 봅니다.

Humidity 수치 · 23값

공기 중 습도 조건을 나타내는 값입니다.

예상: 온도 및 작물 조건과 함께 비료 선택에 간접 영향을 줄 수 있습니다. 단독 신호는 실제 탐색에서 약했습니다.

Moisture 수치 · 41값

토양의 수분 상태를 나타내는 값입니다.

예상: 영양소 상태와 결합할 때 비료 요구량을 더 잘 구분할 수 있습니다. 실제로 단일 feature 중 탐색 구분력이 가장 컸고, 인·질소와의 쌍도 강했습니다.

Soil Type 범주 · 5종

토양 종류입니다. 숫자 크기로 비교하지 않고 이름이 다른 그룹으로 처리합니다.

예상: 같은 영양소 값도 토양 종류에 따라 의미가 달라질 수 있어 토양 × 영양소 상호작용 후보입니다.

Crop Type 범주 · 11종

재배 작물 종류입니다. 순서가 없는 범주형 feature입니다.

예상: 작물별 필요한 영양 조건이 다를 수 있으므로 환경·토양·영양소 효과의 기준을 바꾸는 역할을 기대합니다.

Nitrogen 수치 · 39값

질소 상태를 나타내는 값입니다.

예상: 인·칼륨과의 균형이 비료 종류 구분에 중요합니다. 실제 질소 × 인 조합이 두-feature 탐색에서 가장 강했습니다.

Potassium 수치 · 20값

칼륨 상태를 나타내는 값입니다.

예상: 질소·인과 함께 N-P-K 구성 차이를 표현합니다. 단독보다 칼륨 × 인, 질소 × 칼륨 조합을 우선 검증합니다.

Phosphorous 수치 · 43값

인 상태를 나타내는 값입니다. 원본 열 이름의 철자를 그대로 사용합니다.

예상: 질소·수분과 결합한 구분력이 강했습니다. E004에서 이 조합들을 별도 범주로 표현해 성능이 개선됐습니다.

같은 feature도 여러 방식으로 표현할 수 있습니다

  • 원 수치(raw numeric): 값의 크기와 가까운 정도를 그대로 사용합니다. 현재 기준선의 기본 표현입니다.
  • 범주(category): 값 사이의 거리보다 “서로 다른 상태”로 봅니다. 고유값이 14~43개로 적어 별도 실험 후보지만, 아직 전체 범주화 결과는 확정되지 않았습니다.
  • 상호작용(interaction): 두 값을 하나의 조건으로 묶습니다. E004는 영양소·수분 쌍 5개를 추가해 MAP@3을 0.309568에서 0.319455로 높였으므로 현재 채택한 표현입니다.
  • Target encoding: 각 조건에서 비료별 빈도를 확률 feature로 바꿉니다. 누수 방지가 필수이며, 91개를 한꺼번에 추가한 E005는 성능이 하락해 보류했습니다.
  • ID: 행 식별자일 뿐 실제 예측 시점의 원인 정보가 아니므로 모델 입력에서 제외합니다.

원본 데이터에 단위 설명이 없어 온도·습도·영양소 값에 임의 단위를 붙이지 않았습니다. 또한 이 분석은 연관성을 검증하며 인과효과를 주장하지 않습니다.

무엇을 예측하며, 어느 방향이 좋은가

Target: Fertilizer Name

각 행에서 정답은 7종 비료 중 하나입니다. 그러나 제출할 때는 가능성이 높은 비료 3개를 서로 다르게, 확률 순서대로 적습니다. 클래스 이름에는 크고 작음의 순서가 없습니다.

최종 목표

MAP@3 ↑ 1.0

클수록 좋고 이론적 최고는 1입니다. 모든 행의 정답을 첫 번째 후보로 맞히면 1점입니다. 정답이 2위면 0.5점, 3위면 약 0.333점, 상위 3개 밖이면 0점입니다.

지표좋은 방향이 보고서에서 읽는 법
OOF MAP@3클수록 좋음 · 최고 1모델 선택의 주지표입니다. 현재 최고 E004는 0.319455이며 빈도 기준선 0.278485보다 높습니다.
Log loss작을수록 좋음 · 최저 0정답에 높은 확률을 주는지 봅니다. 틀린 답을 지나치게 확신하면 큰 벌점을 받습니다.
Fold 표준편차작을수록 안정적 · 최저 0데이터를 다섯 번 나눴을 때 점수가 얼마나 흔들리는지 봅니다. 낮으면 우연한 분할에 덜 민감합니다.
Top-3 recall클수록 좋음 · 최고 100%특정 비료가 정답일 때 상위 3개 후보 안에 들어간 비율입니다. 취약한 클래스를 찾는 진단값입니다.
Train/test 총변동거리0에 가까울수록 유사두 데이터의 값 분포 차이입니다. 예측 점수가 아니라 분포 이동 위험을 보는 진단값입니다.
