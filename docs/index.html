Data Study Bank

데이터를 이해하고, 검증 가능한 가설을 세우고, 실험으로 확인하는 과정을 기록합니다. 점수보다 재현 가능한 분석과 의사결정을 우선합니다.

첫 번째 대회 준비 중
01 / UNDERSTAND

데이터 이해

변수 의미, 결측치, 분포와 타깃 구조를 살펴보고 분석 질문을 정리합니다.

02 / VALIDATE

검증 설계

데이터 누수를 막고 실제 일반화 성능을 판단할 수 있는 검증 방식을 만듭니다.

03 / ITERATE

모델 개선

베이스라인에서 시작해 피처와 모델의 효과를 하나씩 측정하고 기록합니다.
