02 / 지금 어디까지 왔나

데이터 진단부터 후보 선정까지 완료했습니다.

대회의 평가 항목과 직접 연결되는 작업을 우선했고, 원본 데이터와 공식 검증 기준은 고정했습니다.

완료 · DATA

데이터 구조와 위험 진단

정상 20,000행, 이상 600행을 보존적으로 통합했습니다. 이상 비율 2.91%, 0.1초 연속 구간의 다수 gap, 정상·이상의 수집일 분리, 정확 중복 1개를 확인했습니다.

완료 · VALIDATION

누수 방지 검증 고정

시간적으로 붙은 행을 섞지 않고 segment 단위 3-fold로 나눴습니다. timestamp·파일명·행 번호·segment 길이를 feature에서 제외하고 threshold도 각 training fold 안에서만 선택했습니다.

완료 · MODEL

세 가지 공식 모델 비교

Logistic Regression, Random Forest, LSTM-Autoencoder를 같은 segment 검증에서 비교했습니다. E001 Random Forest가 최고이며 5개 seed robustness까지 완료했습니다.

완료 · ERROR

미탐·오경보 조건 분석

E001의 기준 seed에서 오경보는 0개, 미탐은 4개였습니다. 미탐의 상부 진동 RMS 중앙값은 0.0446으로 탐지된 이상 0.4689보다 현저히 낮았습니다.

완료 · GUIDEBOOK

가이드북 방식 재현 진단

raw 100-sample LSTM-Autoencoder를 최대 200 epoch로 실행했고 92 epoch에서 조기 종료했습니다. F1 1.0을 얻었지만 공식 후보 선정에서는 제외했습니다.

남음 · FIELD POLICY

현장 경보 정책 문서화

E001의 threshold, 연속 경보 횟수, cooldown, 불확실 구간 재검사 규칙을 확정해야 합니다. 실제 미래 운전 데이터 확보 전에는 정책을 가설로 표시합니다.

03 / 대회 주제와의 연결

높은 점수보다 “언제 믿을 수 있는가”를 설명합니다.

대회 주제는 진동·전류로 유압펌프 이상을 조기에 탐지하고, 미탐지와 오경보 조건을 분석하는 것입니다.

이상 탐지

상부·하부 진동과 전류의 평균, RMS, 변동, 분위수, 추세, 채널 간 상관을 구간별로 요약해 정상과 이상을 구분합니다.

오류 조건

단순 성능표에서 끝내지 않고 FN 4개가 낮은 진동 강도에 집중된다는 사실을 확인했습니다. 이는 약한 이상을 위한 별도 경보 정책이 필요하다는 뜻입니다.

현장 활용

낮은 threshold의 ‘주의’와 높은 threshold가 연속된 ‘경보’를 분리하고, cooldown으로 같은 사건의 반복 알림을 묶는 방향을 제안합니다.

재현성과 정직한 한계

동일 split·metric·threshold 규칙으로 모델을 비교하고, test·onset label이 없다는 사실을 숨기지 않습니다. 조기탐지 시간은 현재 점수에서 도출하지 않습니다.

05 / 사용자가 궁금한 F1 1.0

F1 1.0은 “그 평가셋에서 완벽”이라는 뜻이지,
“미래에도 완벽”이라는 뜻이 아닙니다.

F1 = 정밀도와 재현율의 조화평균

F1 = 2 × (Precision × Recall) ÷ (Precision + Recall). F1이 1.0이 되려면 평가한 표본에서 오경보(FP)와 미탐(FN)이 모두 0이어야 합니다.

1.0000E001의 3개 fold 중 한 fold

Random Forest가 특정 fold의 정상 200개와 이상 7개를 모두 맞혔습니다. 그러나 나머지 fold까지 합친 공식 OOF F1은 0.8947입니다. 작은 평가셋에서는 7개 이상을 모두 맞히는 한 번의 fold가 쉽게 1.0이 될 수 있습니다.

1.0000D000 가이드북 재현 · 비정식

100-sample sequence가 실제 timestamp gap을 넘고, 평가할 데이터의 정답을 사용해 threshold를 선택했습니다. 시험 답을 임계값 선택에 반영한 셈이라 점수가 낙관적으로 치우칩니다. 공식 모델 순위에 사용할 수 없습니다.

따라서 두 1.0은 의미가 다릅니다.

E001의 한 fold 1.0은 올바른 검증 안에서 나온 부분 결과지만 전체 성능은 아닙니다. D000의 1.0은 검증 계약이 다른 진단값이며 누수 때문에 일반화 성능으로 해석할 수 없습니다. 모델 이름보다 데이터 분할과 threshold 선택 시점을 먼저 확인해야 합니다.

06 / 미래를 예측할 수 있는가

현재 답은 “아직 증명하지 못했다”입니다.

현재 모델은 이미 수집된 짧은 구간이 알려진 이상 상태와 닮았는지를 판정합니다. 실제 고장이 일어나기 전에 경고할 수 있는지는 별개의 질문입니다.

A

고장 시작 시각이 없습니다.

각 파일은 구간 전체의 정상/이상만 표시합니다. 모델이 고장 전에 반응했는지, 고장 후 상태를 알아본 것인지 구분할 기준점이 없습니다.

B

정상과 이상이 서로 다른 날짜입니다.

정상은 2022-07-12, 이상은 2022-07-17에 수집됐습니다. timestamp는 feature에서 뺐지만, 날짜별 운전조건 변화가 센서 신호에 남아 있을 가능성은 현재 데이터만으로 제거할 수 없습니다.

C

완전히 새로운 미래 운전일 시험이 없습니다.

segment 교차검증은 인접 행 누수를 막지만, 다른 날·다른 부하·다른 설비에서의 일반화까지 보장하지 않습니다. 별도 test나 prospective run이 필요합니다.

D

현재 입증한 것은 이상 구간 판정입니다.

정확한 표현은 “과거 데이터의 독립 segment에서 이상 상태를 F1 0.8947로 판정했다”입니다. “고장을 미리 예측했다” 또는 “몇 초 전에 탐지했다”는 표현은 아직 사용할 수 없습니다.

가능성을 시험할 모델은 만들었지만, 미래 예측력은 새 데이터로 검증해야 합니다.

고장 onset이 기록된 여러 날짜·부하·설비의 시간순 데이터에서 모델과 threshold를 고정한 채 먼저 예측하고, 그 뒤 정답을 열어 lead time·미탐·시간당 오경보를 측정해야 비로소 예지보전 성능을 말할 수 있습니다.

  3. 03

    모델과 threshold를 잠근 뒤 미래 구간에 적용해 lead time, 사건 단위 recall, 시간당 false alarm을 평가합니다.

    검증
  4. 04

    약한 이상 보완 실험

    현재 FN이 집중된 저진동 이상을 대상으로 주파수·변화율 feature 또는 2단계 경보가 실제 recall을 높이는지 formal experiment로 확인합니다.

    후속

현재의 가장 정직한 결론: Random Forest는 누수 방지 교차검증에서 가장 좋은 이상 구간 판정기입니다. 그러나 F1 1.0 진단은 미래 예측의 증거가 아니며, 실제 예지보전 주장은 onset이 있는 미래 운전 데이터 검증 이후에만 가능합니다.
