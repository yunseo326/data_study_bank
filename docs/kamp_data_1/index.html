04 / 해석과 한계

좋은 검증 설계가
모델보다 앞섭니다.

A

복제 행이 검증 점수를 부풀릴 수 있습니다.

같은 측정 벡터가 학습과 검증에 나뉘면, 새로운 생산 조건을 맞힌 것처럼 보일 수 있습니다. 분할 단위를 원천 ID·생산 시점과 함께 조사해야 합니다.

B

제품과 라벨 유무에 따라 분포가 다릅니다.

24개 변수의 KS 거리 중앙값은 라벨 CN7↔RG3 0.229, 무라벨 CN7↔RG3 0.407입니다. 같은 제품에서도 라벨↔무라벨 차이가 CN7 0.353, RG3 0.316입니다. 이는 분포 차이를 뜻하지만 원인이나 실제 성능 저하를 증명하지는 않습니다.

C

측정값은 파일별로 표준화된 것으로 보입니다.

네 파일에서 측정 변수는 거의 평균 0, 표준편차 1입니다. 원래의 물리 단위와 기준을 확인하기 전까지 제품 간 수치 크기를 직접 비교하거나 현장 임계값으로 쓰기 어렵습니다. 라벨 파일의 Clamp_Open_Position은 상수입니다.

이번 보고서에서 아직 알 수 없는 것

누수 방지 검증에서의 F1·재현율, 실제 검사 우선순위의 효익, 라벨 충돌의 원인, 제조 시점 이후에만 알 수 있는 변수의 존재. 이들은 후속 확인과 실험의 대상입니다.

05 / 다음 단계

검증 가능한 순서로
한 걸음씩.

  1. 01

    라벨과 중복의 출처 확인

    원본의 Y/N 정의, 생산 시점·제품·원천 ID, 같은 측정값에 다른 판정이 생긴 이유를 확인합니다.

    우선
  2. 02

    Primary Validation 고정

    중복 그룹과 시간·제품 경계를 고려한 분할을 정하고, 불량 재현율·정밀도·F1·PR-AUC 및 검사 용량별 성과를 정의합니다.

    설계
  3. 03

    기준 모델과 대안 비교

    단순 기준선과 두 가지 이상 모델을 동일 분할에서 비교합니다. 제품별 결과, 확률 보정, False Negative·False Positive를 함께 봅니다.

    실험
  4. 04

    검사 우선순위로 연결

    검사 가능 수량을 정해 위험도 순으로 선별하고, 제품·공정 조건별 실패 구간과 현장 의사결정 규칙을 제안합니다.

    적용

이 보고서는 예측 결과가 아니라, 믿을 수 있는 예측을 만들기 위한 데이터 점검 기록입니다.
