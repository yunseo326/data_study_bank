## 읽기 규칙

- 일반 작업 재개, 코드 수정, formal experiment 실행 때는 이 디렉터리를 기본 탐색 대상에 포함하지 않는다.
- 대회 참가 여부, 문제 정의, 제출 규칙, 심사 전략 또는 과거 제안서의 맥락을 검토할 때만 관련 하위 디렉터리를 연다.
- 공식 규칙이 갱신될 수 있으므로 저장된 문서만으로 제출 조건을 확정하지 않는다. 실행 전 공식 페이지와 Q&A를 다시 확인한다.
- 이곳의 데이터 샘플은 모델 학습용 원본 데이터로 취급하지 않는다. formal experiment에 사용할 데이터는 검증 후 `data/raw/`에 별도로 배치한다.
