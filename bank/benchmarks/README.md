# 모델 평가 기준

## 무엇을 비교하는가

모델 성능은 `우리 OOF ROC AUC`를 가장 먼저 봅니다. Public LB는 보조 확인값으로 사용합니다.

같은 점수라도 필요한 모델 수, 폴드 수, 외부 데이터, 학습 시간에 따라 의미가 다릅니다. 따라서 단일 모델은 공개 단일 모델과, 앙상블은 공개 앙상블과 비교합니다.

## 고정 규칙

1. 기본 검증 분할과 random seed를 고정한다.
2. 한 실험에서는 한 변수만 바꾼다.
3. 모든 실험은 OOF 점수와 변경 이유를 기록한다.
4. Public LB가 올라도 OOF가 악화되면 개선으로 확정하지 않는다.
5. 공개 모델 점수는 원문 링크와 모델 복잡도를 함께 기록한다.

## 파일

- `public_models.csv`: 비교할 공개 모델과 출처
- `our_experiments.csv`: 우리가 수행한 실험과 점수

`model_bank.py`가 실험 완료 시 OOF 점수, fold 표준편차, 실행 시간과 변경 요소를 이 표에 기록합니다. 대시보드는 완료된 실험 중 최고 OOF 점수를 자동으로 표시합니다.
