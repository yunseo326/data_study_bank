가장 큰 선택 · 모델 계열

같은 16개 변수와 같은 fold에서 초기 LightGBM은 0.968502로 CatBoost 0.963737보다 +0.004765 높았습니다. 이번 데이터에서는 범주형 전용 모델의 기본 설정 이점보다 LightGBM의 트리 성장 방식이 더 잘 맞았습니다.

모델 계열 변경의 효과가 이후 개별 하이퍼파라미터 조정보다 훨씬 컸습니다.

가장 큰 조정 · 학습 상한

E004에서 최대 트리를 1,500개에서 3,000개로 늘린 E005가 +0.000444 개선됐습니다. 조기 종료가 각 fold의 적정 시점을 고르므로, 기존 상한이 학습을 너무 일찍 막았던 것으로 해석됩니다.

복잡도와 샘플링

리프 수를 31에서 63으로 늘린 E006은 +0.000135, 매 트리마다 80%의 행을 다시 뽑게 한 E008은 E006 대비 +0.000115 개선됐습니다. 더 세밀한 상호작용과 약한 무작위성이 모두 도움이 됐습니다.

채택하지 않은 변경

min_child_samples를 20에서 50으로 높인 E007은 E006보다 -0.000040 낮았습니다. 잎을 지나치게 크게 제한해 소수 패턴을 놓친 것으로 보고 되돌렸습니다.

검증 설계와 신뢰도

어떻게 비교했나

  1. 타깃 비율을 유지하는 shuffled Stratified 5-fold, seed 326
  2. 각 fold 약 60만 행으로 학습하고 약 15만 행으로 검증
  3. 범주 인코딩과 모델 학습은 검증 데이터를 보지 않고 fold 안에서 수행
  4. 모든 실험을 같은 fold의 OOF ROC AUC로 비교
  5. 평균뿐 아니라 fold 표준편차로 흔들림 확인

E008 fold 표준편차는 0.000199로 작아 특정 fold 하나가 평균을 끌어올린 결과는 아닙니다.

먼저 알아야 할 결론

duration은 점수용과 현실용을 분리합니다

duration은 마지막 연락의 통화시간이며 타깃과의 단변량 연관성이 가장 큽니다. 하지만 통화가 끝난 뒤에야 확정되므로 Kaggle 점수 모델에는 포함하고, 통화 전 고객 선별 모델에서는 제외해 별도 평가합니다.

unknown은 정보 없음 범주입니다

실제 NaN은 없지만 범주형 변수에 unknown이 928,293건 있습니다. 이를 문자 그대로의 결측치로 바꾸거나 최빈값으로 덮지 않고, ‘정보를 알 수 없음’이라는 명시적 범주로 유지합니다.

pdays=-1은 이전 연락 없음입니다

pdays=-1은 ‘이전에 연락한 적 없음’을 뜻합니다. 해당 상태는 672,434행(89.7%)이며, 경과일 수치와 상태 표시를 분리해 실험할 가치가 있습니다.

Kaggle train/test 이동은 작습니다

각 수치형의 KS 통계량과 범주형의 총변동거리를 비교했으며 가장 큰 값은 duration 0.006입니다. 따라서 무작위 층화 검증을 시작점으로 사용할 수 있습니다. 다만 외부 데이터를 추가할 때는 별도로 분포 차이를 검증해야 합니다.

변수 해석과 모델링 주의

day와 month는 마지막 연락 시점입니다

day는 요일이 아니라 월중 일자이고, month는 마지막 연락 월입니다. 월별 양성률 차이는 고객 선호뿐 아니라 계절성과 은행의 캠페인 대상 선정이 섞인 연관성입니다. 연도 정보가 없어 두 변수만으로 신뢰할 만한 시간순 검증을 만들기 어렵습니다.

campaign은 마지막 연락을 포함합니다

campaign은 현 캠페인에서 해당 고객에게 연락한 횟수이며 마지막 연락도 포함합니다. ‘첫 전화 전에 예측’하는지 ‘현재 통화 후 예측’하는지에 따라 사용할 수 있는 값이 달라지므로 모델 목적을 먼저 고정해야 합니다.

balance는 유로 단위 연평균 잔액입니다

단순 현재 잔액이 아닙니다. 음수와 큰 양수가 함께 있으므로 일반 로그 변환은 바로 적용할 수 없습니다. 트리 모델의 원값 기준선을 먼저 만들고, 필요하면 부호를 보존하는 변환만 한 변수 실험으로 비교합니다.

외부 데이터는 학습 폴드에만 추가합니다

Kaggle train/test는 합성 데이터이므로 외부의 실제 은행 마케팅 데이터를 섞더라도 검증 폴드는 Kaggle train으로 유지합니다. 외부 행은 각 학습 폴드에만 추가하고, 데이터 집단별 분포와 성능을 함께 확인해야 실제 Kaggle 테스트에 도움이 되는지 판단할 수 있습니다.

현재 결론과 다음 실험

  1. 확인: LightGBM 계열이 CatBoost와 XGBoost 기준선보다 높았고, E008이 현재 최고입니다.
  2. 발견: 범주형 명시, 학습 상한, 리프 수, 행 샘플링은 개선됐지만 min_child_samples=50은 평균 AUC를 낮췄습니다.
  3. 중요성: 단순 설정 조정만으로 얻은 개선은 제한적이며, 예측 상관도 높아 고정 혼합 이득도 작습니다.
  4. 다음 1순위: 공개 강한 단일 모델과의 피처·검증 차이를 대조한 뒤, 근거가 있는 피처 가설 하나를 고정 fold에서 검증합니다.
  5. 다음 2순위: 외부 은행 마케팅 데이터를 쓸 경우 Kaggle 검증 fold는 그대로 두고 학습 fold에만 추가해 데이터 집단 차이를 확인합니다.
  6. 현실 트랙: 실제 사전 타기팅 목적이라면 duration 없는 E002를 별도 기준선으로 개선해야 합니다.
