# 진행사항

## Bank 01 — 데이터 이해와 1차 EDA (2026-09-09)

- 목적: 모델링 전에 데이터 구조, 품질, 타깃 분포, train/test 차이와 누수 위험을 확인한다.
- 입력: `bank/data/train.csv`, `bank/data/test.csv`, `bank/data/sample_submission.csv`
- 확인: train 750,000행, test 250,000행, 예측 변수 16개, 타깃 양성률 12.07%
- 품질: 실제 NaN 없음. 범주형 `unknown`은 별도 결측 표현으로 존재한다.
- 품질: ID/타깃을 제외한 완전 중복과 train/test 동일 피처 행은 발견되지 않았다.
- 분포: 수치형 KS와 범주형 총변동거리 기준으로 큰 train/test 이동은 발견되지 않았다.
- 패턴: `duration`의 단변량 연관성이 가장 강하고, `poutcome`, `balance`, `month`가 뒤를 이었다.
- 위험: `duration`이 통화 종료 후 생성되는 값이면 사전 타기팅에서는 누수다.
- 해석: `pdays=-1`은 이전 연락 없음 상태로 보이지만 `previous=0`, `poutcome=unknown`과 완전히 일치하지 않는다.
- 산출물: `docs/index.html`, `logs/result/bank_eda_summary.json`, `bank/src/eda_bank.py`
- 다음 우선순위: Stratified 5-Fold 기준선을 만든 뒤 `duration` 포함/제외만 바꾸어 비교한다.

- 산출물: `bank/README.md`와 HTML 보고서에 원문에서 확인한 정보를 반영했다.

## Bank 03 — 공개 모델 벤치마크 구성 (2026-09-09)

- 목적: 우리의 OOF ROC AUC가 어느 수준인지 공개 모델과 공정하게 비교한다.
- 비교 기준: 단일 모델과 대규모 앙상블을 분리하고, 모델 복잡도와 출처를 함께 기록한다.
- 공개 기준: MLP 0.974, 강한 단일 XGBoost 0.975782, 공개 상위 앙상블 약 0.9772~0.9774 CV.
- 현재 평가: EDA는 완료했지만 기준 모델이 없어 성능 점수는 아직 평가하지 않는다.
- 산출물: `bank/benchmarks/public_models.csv`, `bank/benchmarks/our_experiments.csv`, `bank/benchmarks/README.md`와 HTML 비교 대시보드.
- 다음 통과 기준: 고정된 Stratified 5-Fold에서 첫 OOF ROC AUC를 생성한다.

## Bank 04 — 공식 변수 정의와 해석 보완 (2026-09-10)

- 목적: Kaggle 설명, UCI 변수 사전, 원 연구 논문을 대조해 변수 의미와 모델링 해석을 바로잡는다.
- 수정: `unknown`을 일반 결측값이 아닌 ‘정보 없음’이라는 명시적 범주로 정리했다.
- 수정: `pdays=-1`은 공식적으로 이전 연락 없음이며, `day`는 요일이 아닌 월중 일자임을 명시했다.
- 수정: `balance`는 유로 단위 연평균 잔액이고, `campaign`은 마지막 연락을 포함한 현 캠페인 연락 횟수임을 반영했다.
- 해석: `duration`은 마지막 통화시간이므로 Kaggle 점수 모델에는 포함하되, 통화 전 사전 타기팅 모델에서는 제외하는 두 평가 트랙을 제안했다.
- 해석: 월별 차이는 계절성과 캠페인 운영이 섞인 연관성이며, 연도 정보가 없어 `month`만으로 시간순 검증을 만들지 않는다.
- 원본 데이터 실험: UCI 원본은 학습 폴드에만 추가하고 Kaggle train 검증 폴드는 유지해 합성 테스트 분포에 대한 개선 여부를 평가한다.
- 산출물: `bank/VARIABLES.md`, 갱신된 GitHub Pages HTML과 재현 스크립트.
- 다음 우선순위: 동일한 Stratified 5-Fold에서 `duration` 포함 기준 모델을 먼저 만들고, 제외 실험은 그다음 한 변수만 바꿔 비교한다.

## Bank 05 — 재현 가능한 모델링 프레임워크와 기준선 (2026-09-10)

- 목적: 고정 검증, 실험 기록, 예측 검증과 대시보드 갱신을 하나의 재현 가능한 학습 흐름으로 연결한다.
- 구현: seed 326의 Stratified 5-Fold, fold별 전처리, OOF·test 예측 저장, 제출 스키마 검증과 세그먼트 AUC 분석을 자동화했다.
- E001: 16개 피처 CatBoost 기준선 OOF AUC 0.963737, fold 표준편차 0.000202, 실행 시간 12.56분.
- E002: `duration`만 제외한 기준선 OOF AUC 0.845737, fold 표준편차 0.000563, 실행 시간 12.23분.
- 발견: `duration` 제외로 OOF AUC가 0.118000 하락했다. 통화 종료 후 정보가 Kaggle 점수의 큰 부분을 설명한다.
- 해석: 두 실험 모두 fold 편차가 작아 비교 결과는 안정적이지만, E001은 1차 목표 0.970에 0.006263 부족하다.
- 산출물: 모델링 원칙 문서, 고정된 의존성, 학습 스크립트, 단위 테스트, OOF 기반 실험 대시보드.
- E003: E001에 `previous_contacted`만 추가한 결과 OOF AUC 0.963745, 기준 대비 +0.000008, fold 표준편차 0.000233.
- 해석: 변화가 사실상 0이므로 CatBoost가 원래 `pdays=-1` 상태를 이미 충분히 구분한 것으로 본다. 이 파생 피처는 채택하지 않는다.
- 다음 우선순위: 같은 피처와 fold에서 LightGBM을 비교해 현재 목표 미달이 피처보다 모델 설정의 영향인지 확인한다.

## Bank 06 — 모델 비교와 LightGBM 단일 변경 실험 (2026-09-11)

- 목적: CatBoost의 목표 미달이 모델 선택과 설정 때문인지 확인하고, 한 번에 한 요소만 바꿔 단일 모델 OOF 0.970을 시도한다.
- 모델 비교: 같은 피처와 fold에서 LightGBM 0.968502, XGBoost 0.968348로 CatBoost 0.963737보다 높았다.
- E004: 범주형 피처를 명시해 0.968589, 기준 대비 +0.000087. 효과는 작지만 일관된 방향이었다.
- E005: 최대 트리 수만 1,500에서 3,000으로 늘려 0.969033, E004 대비 +0.000445. 기존 학습 상한이 병목이었다.
- E006: `num_leaves`만 31에서 63으로 늘려 0.969168, E005 대비 +0.000134.
- E007: `min_child_samples`만 20에서 50으로 늘린 결과 0.969128, E006 대비 -0.000040으로 기각했다.
- E008: E006에서 `subsample_freq=1`만 적용해 0.969283, E006 대비 +0.000116으로 현재 최고가 됐다.
- 안정성: E008 fold 표준편차는 0.000199이며 다섯 fold 모두 E006보다 상승했다.
- 목표 판단: 최초 LightGBM 대비 +0.000781 개선했지만 0.970에는 0.000717 부족해 계획한 설정 후보를 소진하고 중단했다.
- 피처 중요도: E008 gain의 약 54%가 `duration`에 집중됐고, `month`, `balance`, `poutcome`, `contact`가 뒤를 이었다. 이는 인과효과가 아니라 모델 분할 기여도다.
- 취약 구간: `dec`, `mar`, `oct`, `sep`과 `poutcome=success`처럼 양성률이 높은 비교적 작은 집단에서 그룹 내부 AUC가 낮았다.
- 혼합 진단: XGBoost와 E008의 고정 50:50 혼합은 0.969294로 E008보다 약 +0.000010에 그쳤다. 예측 상관이 높아 현재 단계에서는 앙상블 이득이 작다.
- 다음 우선순위: 공개 강한 단일 모델과의 피처 차이를 대조해 근거 있는 피처 가설 하나를 검증하거나, UCI 원본을 학습 fold에만 추가하는 별도 실험을 설계한다.
- 산출물: `src/analyze_models.py`, `logs/result/model_analysis.json`, 갱신된 실험 대시보드와 GitHub Pages 보고서.

## Bank 08 — 학습자 중심 Feature·목표·로드맵 설명 (2026-09-12)

- 목적: 보고서가 결과표를 보여주는 데서 끝나지 않고, 사용자가 입력 변수와 평가 목표 및 다음 분석 방향을 직접 판단할 수 있게 한다.
- 목표 설명: `y=1`의 의미, 모델이 내는 0~1 예측값, ROC AUC는 1에 가까울수록 좋고 0.5는 무작위 순위 수준이라는 해석을 추가했다.
- 트랙 구분: `duration`을 포함하는 Kaggle 점수 트랙과 제외하는 현실 사전 타기팅 트랙의 목적이 달라 점수를 직접 우열 비교하지 않음을 명시했다.
- Feature 설명: 수치형·범주형·표현/변환(representation)·상호작용(interaction)별로 실제 변수, 모델이 보는 정보, 예상 영향, 실험 후보와 우선순위를 연결했다.
- 해석 안전장치: 예상 영향은 인과나 성능 개선의 확정이 아니라 EDA와 업무 의미에서 세운 가설이며 동일 fold의 한 변수 실험으로 채택한다고 명시했다.
- 로드맵: 문제 이해부터 검증, 기준선, 설정 개선, 현재 피처 가설, 외부 데이터, 제출·회고까지 6단계 진행 상태를 추가했다.
- 산출물: `src/eda_bank.py`, `docs/index.html`, 보고서 회귀 테스트와 GitHub Pages 게시본.
