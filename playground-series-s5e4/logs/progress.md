# 진행사항

## Podcast 01 — 초기 데이터 진단과 분석 설계 (2026-09-10)

- 입력: `data/train.csv`, `data/test.csv`, `data/sample_submission.csv`
- 확인: train 750,000행, test 250,000행, 예측 변수 10개, 타깃은 `Listening_Time_minutes`
- 타깃: 평균 45.44분, 범위 0~119.97분, 0분 8,551행
- 결측: 에피소드 길이 train 11.61%·test 11.49%, 게스트 인기도 train 19.47%·test 19.53%
- 핵심 패턴: 에피소드 길이와 타깃의 Pearson 상관은 0.917
- 품질 위험: test 길이 7,575분·78,486,264분, 광고 수 2,063개 등 극단 오류가 존재
- 분포: 범주형 test 미관측 수준이 없고 정상 범위의 train/test 수치 분포는 유사
- 검증 방향: seed 326의 shuffled 5-Fold OOF RMSE
- 학습 방식: 공개 상위 해법은 독립 EDA와 기준 모델 완료 후 비교
- 다음 단계: 재현 가능한 EDA와 B000/B001/B002 기준선을 실행하고 오류 구간을 분석

## Podcast 02 — 재현 가능한 EDA와 기준 모델 (2026-09-11)

- 구현: 데이터 계약, 이상값 규칙, 고정 5-Fold, OOF·test 예측, 제출 검증, 세그먼트 RMSE와 피처 중요도를 자동화
- 테스트: 데이터 계약, 이상값, 피처셋, fold 재현성, 길이 선형식, 예측 검증, 결측 세그먼트의 단위 테스트 7개 통과
- B000: 평균 예측 OOF RMSE 27.138370, fold 표준편차 0.029575
- B001: 길이 전용 선형회귀 OOF RMSE 13.543573, B000 대비 13.594797 개선
- B002: 전체 원본 피처 CatBoost OOF RMSE 13.049999, B001 대비 0.493574 개선, 실행 26.33분
- B002 오류 분석: 길이가 있는 662,907행 RMSE 10.416569, 길이 결측 87,093행 RMSE 25.311535
- B002 중요도: 에피소드 길이 91.06%, 광고 수 3.55%, 호스트 인기도 2.06% 순
- P001: 예측을 0~120분으로 제한해 RMSE 13.049970, 개선은 0.000030으로 매우 작음
- E101: 길이 0~120분 밖의 값만 결측 처리한 결과 RMSE 13.052363, B002보다 0.002363 악화되어 채택하지 않음
- E101 test 진단: ID 804434와 806597의 예측이 각각 89.88→44.60, 95.14→43.72로 변해 극단값 안전성은 높아졌지만 OOF 근거가 부족함
- 현재 최선: P001. 실질적인 다음 우선순위는 길이 결측 행의 정보 복원 또는 별도 모델링
- 후속 구현: E202 전역 중앙값과 E203 팟캐스트·회차 그룹 중앙값 대체를 학습 fold 내부에서만 계산하도록 추가
- 산출물: GitHub Pages용 `docs/index.html`, EDA JSON, 실험 레지스트리, 실험별 OOF·submission·진단 파일

## Podcast 03 — 결측 구조와 OOF 잔차 분석 (2026-09-11)

- 분석 원칙: B002의 저장된 OOF 예측만 사용해 잔차를 계산하고 원본 CSV는 읽기 전용으로 유지
- 결측 분포: 주요 결측 조합의 train/test 최대 차이는 0.13%p 미만으로 안정적
- 결측 메커니즘: 에피소드 길이·게스트 인기도 결측률은 Podcast_Name과 Episode_Title에 따라 달라지며 그룹별 패턴이 test에서도 반복
- 오류 집중: 길이 결측 87,093행(11.61%)이 B002 전체 제곱오차의 43.69%를 차지
- 그룹 중앙값 검증: Podcast_Name×Episode_Title 중앙값의 교차 적합 길이 RMSE 33.30분으로 전역 중앙값 32.98분보다 악화
- 약한 순위 신호: 실제 길이 결측 행에서 대체 길이 Q1→Q5의 타깃 평균은 40.52→45.24분, 상관 0.065
- 잔차 구조: B002 평균 잔차는 0.022분이지만 예측 10분위별 RMSE는 3.98~18.24로 이분산성이 큼
- E201: 수치형 결측 플래그 추가 OOF RMSE 13.049710, B002보다 0.000289 개선
- E201 세그먼트: 길이 결측 RMSE 25.311535→25.308353 개선, 길이 있음은 10.416569→10.417174 악화
- 해석: 결측 플래그는 방향은 맞지만 CatBoost 기본 결측 처리와 중복되어 효과가 매우 작음
- 산출물: 재현 스크립트, 결측·잔차 JSON/CSV, GitHub Pages 보고서의 결측·잔차 섹션

## Podcast 04 — 사용자 중심 보고서 설명 보강 (2026-09-12)

- 확인: 기존 보고서에는 변수 사전과 실험 순서가 있었지만, 각 feature가 무엇이고 어떤
  영향을 예상하는지, 표현 방식과 interaction 후보를 사용자가 한 흐름으로 읽기 어려웠음
- 변경: 10개 예측 feature와 ID를 수치·범주·식별자로 구분하고 의미, 확인된 영향,
  수치/범주/결측 플래그/interaction 표현 후보를 직접 설명함
- 구분: 데이터로 확인된 상관·그룹 평균·중요도와 아직 검증 전인 interaction 가설을
  명확히 나누고, 높은 feature 값 자체가 좋다는 뜻은 아님을 명시함
- 변경: 타깃은 분 단위 연속값이며 RMSE는 작을수록 좋고 이론적 최저가 0임을 설명함
- 변경: 문제 이해부터 데이터 진단, 검증, 길이 결측 개선, 모델 확장, 제출과 새 가설까지
  8단계 로드맵을 추가하고 현재 위치를 길이 결측 병목 개선 단계로 표시함
- 다음: P001을 현재 기준으로 유지하며 길이 결측 구간의 feature 표현을 한 요소씩 검증함
