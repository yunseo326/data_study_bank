## Podcast 01 — 초기 데이터 진단과 분석 설계 (2026-09-10)

- 입력: `data/train.csv`, `data/test.csv`, `data/sample_submission.csv`
- 확인: train 750,000행, test 250,000행, 예측 변수 10개, 타깃은 `Listening_Time_minutes`
- 타깃: 평균 45.44분, 범위 0~119.97분, 0분 8,551행
- 결측: 에피소드 길이 train 11.61%·test 11.49%, 게스트 인기도 train 19.47%·test 19.53%
- 핵심 패턴: 에피소드 길이와 타깃의 Pearson 상관은 0.917
- 품질 위험: test 길이 7,575분·78,486,264분, 광고 수 2,063개 등 극단 오류가 존재
- 분포: 범주형 test 미관측 수준이 없고 정상 범위의 train/test 수치 분포는 유사
- 검증 방향: seed 326의 shuffled 5-Fold OOF RMSE
- 학습 방식: 공개 상위 해법은 독립 EDA와 기준 모델 완료 후 비교
- 다음 단계: 재현 가능한 EDA와 B000/B001/B002 기준선을 실행하고 오류 구간을 분석

## Podcast 02 — 재현 가능한 EDA와 기준 모델 (2026-09-11)

- 구현: 데이터 계약, 이상값 규칙, 고정 5-Fold, OOF·test 예측, 제출 검증, 세그먼트 RMSE와 피처 중요도를 자동화
- 테스트: 데이터 계약, 이상값, 피처셋, fold 재현성, 길이 선형식, 예측 검증, 결측 세그먼트의 단위 테스트 7개 통과
- B000: 평균 예측 OOF RMSE 27.138370, fold 표준편차 0.029575
- B001: 길이 전용 선형회귀 OOF RMSE 13.543573, B000 대비 13.594797 개선
- B002: 전체 원본 피처 CatBoost OOF RMSE 13.049999, B001 대비 0.493574 개선, 실행 26.33분
- B002 오류 분석: 길이가 있는 662,907행 RMSE 10.416569, 길이 결측 87,093행 RMSE 25.311535
- B002 중요도: 에피소드 길이 91.06%, 광고 수 3.55%, 호스트 인기도 2.06% 순
- P001: 예측을 0~120분으로 제한해 RMSE 13.049970, 개선은 0.000030으로 매우 작음
- E101: 길이 0~120분 밖의 값만 결측 처리한 결과 RMSE 13.052363, B002보다 0.002363 악화되어 채택하지 않음
