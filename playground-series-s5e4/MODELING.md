# Podcast 모델링 프레임워크

## 판단 순서

문제 이해 → 데이터 품질 → 고정 검증 → 기준선 → 단일 변수 실험 → 오류 분석 → 모델 비교 → 원본 데이터 → 앙상블 순서로 진행합니다.

주지표는 seed 326의 shuffled 5-Fold OOF RMSE입니다. Kaggle 점수는 OOF 개선이 test에도 이어지는지 확인하는 보조 지표로 사용합니다.

## 고정 검증

- `id`는 모델 입력에서 제외하고 분포 진단에만 사용합니다.
- 모든 대체값, 인코딩, 선형 기준식과 모델은 학습 fold에서만 학습합니다.
- 전체 RMSE와 fold 표준편차를 기록합니다.
- 에피소드 길이 결측, 길이 구간, 이상값, 광고 수, 감정별 RMSE를 확인합니다.
- 같은 fold 파일을 모든 실험에서 재현하므로 실험 간 차이를 직접 비교할 수 있습니다.

## 이상값 규칙

원본 값은 수정하지 않습니다. 실험용 사본에서만 아래 범위를 벗어난 값을 결측으로 바꿉니다.

- 에피소드 길이: 0~120분
- 호스트·게스트 인기도: 0~100%
- 광고 수: 0~3의 정수

범위는 로컬 데이터의 정상 분포와 변수 의미를 바탕으로 한 가설입니다. 각 규칙은 OOF 개선으로만 채택합니다.

## 다음 단계 규칙

1. B000/B001/B002를 완료하고 B002의 오류 구간을 확인합니다.
2. E101~E104를 한 번에 하나씩 실행합니다.
3. 데이터 품질 처리가 정해진 뒤 E201, E301, E401을 실행합니다.
4. 강한 CatBoost 구성이 정해진 뒤 M001/M002를 같은 피처로 비교합니다.
5. 독립 분석이 끝난 뒤 공개 상위 해법과 비교합니다.
6. 원본 Podcast Listening Time Prediction 데이터는 별도 출처와 라이선스를 확인하고, 각 학습 fold에만 추가합니다. Kaggle 검증 fold는 합성 train 데이터로 유지합니다.
7. 앙상블은 서로 다른 모델의 OOF 예측이 모두 존재할 때만 만들고, 가중치는 OOF에서 결정합니다.

## 채택 기준

- 전체 OOF RMSE가 낮아져야 합니다.
- 개선이 특정 fold 하나에만 의존하지 않아야 합니다.
- 중요한 세그먼트의 큰 악화가 없는지 확인합니다.
- 작은 개선은 실행 비용과 설명 가능성을 함께 고려합니다.
- Kaggle public score만 좋아지고 OOF가 나빠진 변경은 채택하지 않습니다.
