# Conditional References

이 디렉터리는 현재 실험을 실행할 때 매번 읽는 문서가 아니다.

- 일반 작업 재개, EDA, formal experiment, reviewer 판정에서는 이 디렉터리를 자동으로 탐색하지 않는다.
- 사용자가 대회 참여 여부, 전체 전략, 일정, 제출 규정 또는 과거 의사결정의 근거를 묻는 경우에만 관련 대회 폴더를 선택적으로 읽는다.
- 여기의 웹 자료는 저장 시점의 스냅샷이다. 일정·규정·데이터 정의는 실행 전에 공식 페이지의 최신 내용을 다시 확인한다.
- 원본 experiment artifact와 `CURRENT_STATE.md`를 대체하지 않는다.
