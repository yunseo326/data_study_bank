# 2026 하천수위 예측 대회 — AI 계획 수립용 참고자료

> 조건부 참고자료. 일반 작업 재개나 개별 실험 실행 때 자동으로 읽지 않는다. 대회 참여 여부, 전체 전략, 일정, 제출 규정, 데이터 교체 계획을 세울 때만 읽는다.

## 대회 구조와 일정

- 전체 대회: 2026-08-11 ~ 2026-11-25
- 채택 문제 공개: 2026-09-15
- 문제 해결 및 참가신청: 2026-09-15 ~ 2026-11-06
- 문제별 후보 선정(서류평가): 2026-11-09 ~ 2026-11-13
- 최종 발표평가 및 시상: 2026-11-25, KISTI 대전 본원 키움관
- 활성 문제는 공식 목록 기준 7개다.
- 문제해결 부문 시상은 대상 1팀 300만원, 최우수상 1팀 200만원, 우수상 5팀 각 100만원이다. 적합한 결과가 없으면 시상하지 않거나 수상팀 수·내역을 조정할 수 있다.
- 활성 문제 7개와 문제해결 수상 7팀이 일치하고, 공식 설명이 문제별 우수 해결책을 후보로 선정한다고 적고 있어 문제별 1팀 수준의 수상 구조일 가능성이 있다. 이는 추론이며 보장된 배정 규칙은 아니다.

### 발표평가 기준

- 창의성 20점: 독창성, 새로움, 가시적 차별성
- 우수성 50점: 대회 목적과의 연관성, 구체성, 완성도
- 효과성 30점: 흥미·홍보효과, 활용성

정량 RMSE만 낮추는 것으로 충분하지 않다. 후보 선정 뒤에는 방법론의 정당성, 누수 방지, 실무 활용성과 발표 완성도를 함께 준비해야 한다.

## 공식 문제 정의

- 한 행은 관측소 1개와 예측 기준시점 `t`를 나타낸다.
- 목표는 `max(WL(t+1), ..., WL(t+6)) - WL(t)`이며 단위는 m다. 이후 6시간의 모든 수위가 낮으면 target은 음수가 될 수 있다.
- 입력은 `t`까지의 과거·현재 수위, IMERG·지상 강우·레이더 정보, 유역환경 정보다.
- 공식 평가지표는 전체 평가 행에 대한 Global RMSE다.
- 평가 구간은 강우로 정의한 호우사상이다. 도메인 평균 IMERG 시간강우가 0.5 mm/h를 넘는 구간을 찾고, 강우구간 사이 간격이 12시간 이하면 같은 사상으로 연결한다.
- 총 152개 호우사상 중 Train은 122개, Test는 30개다. 동일 사상은 양쪽에 겹치지 않는다.
- 최종 배포 규모는 Train 749,657행, Test 186,263행, 관측소 465개다.
- 최종 식별자는 익명 `station_id`(`ST0001`~`ST0465`), 합성 `timestamp`, 익명 `row_id`(`TR_...`, `TE_...`)다.

### 공식 예비 기준성능

| 모델 | Train 4-fold storm-event OOF Global RMSE |
|---|---:|
| 변화 없음(0 예측) | 0.410 m |
| 과거 수위만 활용 | 0.275 m |
| 강우·기상·유역환경 활용 | 0.244 m |

위 수치는 고정 학습조건의 참고용이며 Test 점수, 통과 기준 또는 수상 기준이 아니다. 과거 문서와 Q&A에는 0.220 등 이전 수치가 남아 있으나, 2026-09-23에 갱신된 공식 문제 페이지의 0.244를 현재 기준으로 삼는다.

## 로컬 파일 판정

`sources/preliminary_sample_296rows.csv`를 읽기 전용으로 확인한 결과:

- 296행 × 26열, 관측소 117개, 고유 시각 157개
- 결측 0개, 중복 `row_id` 0개
- 관측소별 행 수는 1~3개(중앙값 3개)
- target 평균 0.223 m, 중앙값 0.040 m, 표준편차 0.662 m
- 최소 -1.49 m, 99백분위 2.202 m, 최대 7.07 m
- target 0 비율 15.2%, 음수 13.9%, 양수 70.9%
- 유역환경 7개 변수는 각 관측소 안에서 고정값이다.
- `row_id`가 실제 관측소·시각을 포함하고 실제 2017~2019 시각과 숫자형 station ID를 사용한다.

따라서 이 CSV는 최종 익명 데이터와 다르며, 분포 감각과 스키마 초안만 보는 초기 샘플이다. 이 파일의 상관, score, split 결과를 공식 성능 근거로 쓰지 않는다.

## 가장 중요한 무결성 위험: Test 미래행 누수

공식 Q&A의 2026-09-21 문의에 따르면 배포된 Test에는 같은 관측소의 연속 시각 행과 각 시각의 `wl_t`가 함께 있어, 특정 `t` 행에서 이후 행을 참조하면 약 61.8%의 target을 정확히 재구성할 수 있다. 2026-09-23 현재 해당 질문에는 답변이 표시되지 않았다.

하지만 갱신된 공식 문제 설명은 다음을 명확히 금지한다.

- 예측시점 이후의 수위·강우·기상정보 사용
- 동일 평가 데이터의 다른 행을 참조해 미래 수위정보를 얻는 행위
- 익명 관측소·시각을 역추적해 외부 원자료로 정답을 구성하는 행위

AI가 지켜야 할 규칙:

1. Test 추론은 한 행의 공식 입력 컬럼만으로 수행한다.
2. 같은 Test 파일의 후속 행, 미래 timestamp, 미래 `wl_t`를 feature나 후처리에 쓰지 않는다.
3. station별 정렬·shift·rolling을 적용할 때 해당 행 기준 미래 방향을 읽지 않는지 자동 테스트한다.
4. 제출 후보마다 feature lineage와 cutoff 검사를 남긴다.
5. Q&A 답변과 데이터 재배포 여부를 formal baseline 전에 다시 확인한다.

이 규칙을 위반한 score는 높은 성능이 아니라 INVALID로 처리한다.

## 난이도의 실제 원인

### 1. 유효 표본 수가 행 수보다 훨씬 작다

749,657행이지만 일반화 단위는 122개 호우사상이다. 인접 행은 같은 폭우와 같은 관측소 반응을 공유하므로 행 단위 random K-fold는 과도하게 낙관적이다.

### 2. Test가 새로운 호우사상이다

관측소는 겹칠 수 있어도 폭우의 강도·공간분포·진행경로는 새롭다. 모델이 관측소 평균 패턴만 외우면 극단 사상에서 실패한다.

### 3. RMSE는 극단 오차에 민감하다

공식 Q&A 문의자가 보고한 분석에서는 사상별 RMSE 중앙값이 0.105, 최댓값이 0.607이었고 상위 5개 사상이 전체 오차제곱합의 52.6%를 차지했다. 이는 운영사무국 답변이 아닌 참가자 분석이므로 검증이 필요하지만, Global RMSE가 소수 극단 사상에 지배될 가능성을 강하게 시사한다.

### 4. 미래 강우예보가 없다

향후 6시간 최대 상승을 예측하지만 공식 입력은 `t`까지다. 급격한 신규 강우나 공간적으로 이동하는 강우대의 영향을 완전히 알 수 없으므로 irreducible error가 있다.

### 5. 익명화로 외부 결합이 사실상 막힌다

최종 station과 timestamp가 익명이라 실제 WAMIS·기상 원자료를 정당하게 조인하기 어렵다. 공식 페이지도 외부 정보 활용 범위를 운영사무국 안내에 따르도록 제한한다. 외부 데이터 확보를 핵심 전략으로 가정하지 않는다.

## 수상 가능성을 높이는 방향

### 1순위: 검증을 먼저 고정

- Primary Validation은 공식 예비모델과 정렬한 `storm-event group 4-fold CV`를 우선한다.
- 최종 데이터에 `storm_event_id`가 없으면 합성 timestamp의 전역 시간 구간과 12시간 gap을 이용한 그룹 복원 가능성을 검토하되, 공식 정의와 일치하는지 확인한 뒤 version을 고정한다.
- 관측소 기준 random split과 행 기준 random split은 금지한다.
- 각 fold의 사상 수, target tail, 강우 강도를 기록해 fold 난이도 편차를 확인한다.
- Robustness는 Primary를 바꾸지 않고 leave-year-out 또는 사상 강도 구간별 성능으로 별도 확인한다.

### 2순위: 재현 가능한 baseline 사다리

1. 0 예측(RMSE 약 0.410 재현)
2. 과거 수위 변수만 사용한 모델(약 0.275 기준)
3. 전체 공식 feature의 단일 강한 tree model
4. 다른 inductive bias의 모델을 추가한 OOF 기반 ensemble

각 단계는 하나의 가설만 바꾸고 OOF와 event별 진단을 저장한다. 공식 0.244를 먼저 재현하지 못하면 복잡한 모델 탐색을 중단하고 split·feature cutoff·metric을 재점검한다.

### 3순위: 도메인 feature

- 수위 변화율: `wl_t - wl_t_minus_1h`, 3h·6h·12h·24h 변화량
- 수위 가속도와 시간창별 기울기 차이
- 강우 최근성·집중도: 1h/6h/24h의 차이와 비율
- IMERG와 지상강우의 일치·불일치
- 레이더 반사도와 강우 누적의 상호작용
- 유역면적·경사·도시율·하천차수와 강우·수위변화의 상호작용
- station별 과거 target 또는 잔차 통계는 반드시 fold 내부에서만 만들고 OOF-safe 방식으로 적용

물리식을 흉내 낸 복잡한 비율은 분모가 0에 가까울 때 불안정해질 수 있으므로 clipping과 결측 규칙을 config에 기록한다.

### 4순위: 극단 사상과 RMSE 대응

- 평균 RMSE뿐 아니라 event별 RMSE, target 상위 1·5·10% RMSE, 큰 상승 누락률을 본다.
- tail 행 가중 또는 oversampling은 공식 RMSE와 불일치할 수 있으므로 OOF에서 실제 개선이 확인될 때만 채택한다.
- Huber/MAE 계열 loss는 안정적일 수 있지만 큰 오차를 덜 벌주므로 단독으로 공식 RMSE 최적화에 유리하다고 가정하지 않는다.
- 극단 target clip은 bias를 만들 수 있으므로 제출 후처리보다 모델 ensemble과 calibration을 우선한다.

### 5순위: 모델·앙상블

- CPU 기준 우선순위: LightGBM 또는 CatBoost 계열 → HistGradientBoosting/XGBoost 대조 → 선형·단순 기준모델
- `station_id`를 단순 숫자 연속값으로 해석하지 않는다. categorical 처리 또는 규제된 encoding을 사용한다.
- 서로 다른 seed보다 서로 다른 feature set·model family·loss의 OOF 오차 상관이 낮은 조합을 우선한다.
- blend weight는 OOF에서만 학습하고 Test score나 Public Leaderboard에 맞추지 않는다.

### 6순위: 발표평가 준비

- 모델의 정확도뿐 아니라 “6시간 전 대응 의사결정”과 연결한다.
- 강우·유역 특성이 상승량에 어떻게 작용했는지 SHAP/feature effect를 사상별 사례로 설명한다.
- 전체 평균 하나 대신 평상·급상승·극단 사상에서의 안전성과 한계를 제시한다.
- 행 단위 추론과 cutoff 검사로 미래정보를 쓰지 않았음을 재현 가능하게 보여준다.
- 운영 적용 시 예측 주기, 계산시간, 오류 모니터링, 경보 threshold는 모델 산출과 정책 결정의 경계를 분리해 설명한다.

## 참가신청서에서 확인한 제출·법적 조건

- 참가자 전원은 성명, 소속, 이메일, 전화번호 등 개인정보 수집·이용에 동의하며 보유기간은 5년이다.
- 참가신청서는 참가자 정보, 문제명, 팀명, 제안 제목, 데이터 활용·분석 방법론, 추진일정, 예상 결과물을 요구한다.
- 제공 데이터는 승인 목적 밖에서 사용하거나 제3자에게 제공할 수 없다.
- 재식별 가능성을 발견하면 이용을 중지하고 주최측에 알린 뒤 자료를 폐기해야 한다.
- 경진대회 제공 데이터는 대회 완료 뒤 폐기해야 한다.
- 관련 논문·출판물에는 데이터 출처를 명시해야 한다.
- 수상자는 최종 제출물, 소프트웨어 코드, 문서를 주최측에 전달하고 DataON/AIDA 공개에 동의한다.
- 잠재 수상 통지 후 1주 안에 응답하지 않으면 차순위자에게 권리가 넘어갈 수 있다.
- 팀 수상 상금은 대표자에게 지급되며 분배는 팀 내부에서 정한다.
